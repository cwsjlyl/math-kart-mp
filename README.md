# 3D 乘數衝鋒車大獎賽 Math Kart 8 DX v4.0（課堂連線版）

把原有單機「3D 乘數衝鋒車」加上課堂多人連線，保留車庫、6 條賽道、車款烤漆、1–9／2–9／6–9 乘法範圍、觸控、道具、3 圈賽、光門、加速墊、AI，以及賽後 4 倍錯題特訓。

呢個係課堂學習遊戲，**並非官方商業賽車作品**。全部車手同新車款都係原創致敬角色，唔使用任何官方名稱或商標。

## 本機試玩

喺本資料夾開啟一個靜態伺服器，例如：

```bash
python3 -m http.server 4173
```

然後用瀏覽器打開 `http://localhost:4173/`。請用支援 WebGL 嘅瀏覽器（iPad Safari、常見 Chrome／Edge）。單人模式唔需要任何雲端設定，可即時開跑。

## 轉向（人手控制）

轉彎要自己撳左／右（鍵盤 A／←、D／→，或畫面按鈕）。唔撳方向時，架車會沿住而家嘅朝向直行，唔會自動跟住彎道轉；入彎唔轉就會飄向外側，撞到賽道邊界會減速。電腦對手順住賽道行，仍然會自動入彎。

## 車庫操作

車庫分兩頁：第 1 頁揀賽道，第 2 頁揀賽車、車手同開賽。右邊會即時顯示車手肖像同立體賽車預覽。預設車手係「小雲」（彩雲聖若瑟小學校服）；亦可選「小晴」、「李主任」、「小哲」、「疾風迅」。原有四款賽車之外，新增原創致敬車款「赤電號」、「蒼雷號」、「香港的士」同「冒險單車」。電話、平板或嵌入頁面（例如 Google Sites）會顯示「全螢幕」掣，車庫底部嘅「下一頁／單人挑戰 AI／建立房間／加入房間」會固定喺可見畫面內；即使瀏覽器唔准全螢幕，都可以直接選賽道同開賽。賽車車身用較平滑嘅立體烤漆模型。

- **單人挑戰 AI**：同舊版一樣，立即開賽，3 部電腦車對戰。
- **建立房間**：先喺畫面輸入短名／學號（例如「4A 陳小明」；唔會用系統彈窗），跟住即時見到「正在建立房間…」，成功後會顯示大大的 4 位數房號。大廳會顯示已加入同學、車款同就緒名單。最多 4 位真人；房主按「開始比賽」時，空位由電腦車補上（由房主模擬並廣播）。若已有 4 人，就唔會加 AI。
- **加入房間**：喺車庫輸入同一組 4 位數房號（同樣唔用系統彈窗），再按「加入房間」。
- **防跟車抄答案**（預設開啟）：光門位置全場同步，但每部 iPad 獨立出題同左右正確車道，避免跟車抄答案。關掉之後，改由房主出題並同步到各機。

## 連線設定

連線使用 **Supabase Realtime Broadcast**（加密 WebSocket，連接埠 443，較易穿過學校防火牆）。免費專案 `cwsj-math-kart`（新加坡機房）嘅 Project URL 同 **anon public key** 已寫入 `js/net-config.js`。

- **千祈唔好**把 `service_role` key 放進任何前端檔案。
- 前端用 Broadcast 頻道 `cwsj-mk8-<房號>`，無需自建後端或資料庫寫入。
- 房主建立房間後，同學輸入 4 位數房號就可以一齊比賽。單人挑戰 AI 唔需要連線。

## 比賽規則摘要

- 遠端賽車用航位推算 + 指數平滑，避免瞬移；真人車頂有名牌。
- 道具／香蕉／龜殼／炸彈／閃電／墨汁以高優先事件同步。撞擊採用「受擊端自主判定」（本地玩家或房主負責嘅 AI 先算命中，再廣播 `KART_HIT`），避免打兩次。
- 第一位真人衝線後倒數 15 秒（或全體真人完賽即結算），顯示 1st–4th 真人名次同答對率。之後每部裝置各自進行自己嘅 4 倍錯題特訓。
- 比賽期間會嘗試使用螢幕 Wake Lock，減少 iPad 自動鎖機。網絡同步用 `setInterval`（約 20 Hz）同訊息回呼，唔只依賴畫面迴圈。

## 之後若要放到 GitHub Pages（而家未做）

本資料夾已係純前端靜態檔（`base` 相對路徑、已有根目錄 `.nojekyll`）。把整個 `math-kart-mp` 內容推上倉庫即可，例如用 GitHub Actions 的 `peaceiris/actions-gh-pages` 或直接用 `gh-pages` 分支。**唔需要**再喺執行時載入 jsDelivr 或其他 CDN。anon public key 已填好，發佈時請一併包含 `js/net-config.js`，但不要加入 service_role。

## 操作

鍵盤：A／←、D／→ 人手轉向（唔撳就直行），空白鍵／Enter／W／↑ 使用道具。iPad 可用畫面按鈕。比賽中可返回車庫。
